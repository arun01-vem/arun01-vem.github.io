# Certificates

This folder contains certificate PDFs and matching previews shown on the portfolio website.

- `computer-vision-101.pdf` and `computer-vision-101-preview.png`
- `deep-learning-for-developers.pdf` and `deep-learning-for-developers-preview.png`
- `artificial-intelligence-primer.pdf` and `artificial-intelligence-primer-preview.png`
- `ai-data-scientist-appc-certificate.pdf` and `ai-data-scientist-appc-preview.jpg`

The APPC / TBOCWWB AI - Data Scientist certificate is included as a privacy-safe public copy. The preview and linked PDF conceal the family-member name, identifier rows, QR code and unique certificate number; the unredacted uploaded source is not included in this public website assets folder. The course title, issuing organization text, online delivery, training period, course duration and issue date remain visible and are also transcribed on the certificate card.

Each preview links to the corresponding PDF. If replacing a certificate, replace both files and keep their names aligned with `index.html`.
